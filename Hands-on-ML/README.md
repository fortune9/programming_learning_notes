This repository will hold the code I wrote when going over the book *Hands-on Machine Learning with Scikit-Learn & TensorFlow*.

The purpose is to (1) remind me how the algorithms work and (2) help others who wants to learn ML.

## My learning notebooks

Start with [00.setup.ipynb](Notebooks/00.setup.ipynb) for Python environment setup,
package installation, choosing the environment in other notebooks, and small ML
checks. It uses Python 3.13 and the packages in [requirements.txt](requirements.txt).
The setup commands run from this `Hands-on-ML` directory.

My notebooks live in `Notebooks/`; `book-code/` contains reference code from the books
and may have different dependency requirements.
